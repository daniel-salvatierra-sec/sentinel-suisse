# CV suisse pour un poste

Cela **ne te trouve pas le poste**. On n'invente pas de compétences : un A2 ne s'écrit pas C1. Sentinela n'est pas conseillère officielle.

## Ce qui se fait souvent
- Photo professionnelle
- Nationalité et **permis G, B, C ou L**
- Langues avec niveau CEFR
- 1–2 pages, chronologique, dates JJ.MM.AAAA
- Langue de l'annonce ; en allemand, Arbeitszeugnis si tu en as
