# Swiss CV for a job

This **does not get you the job**. We do not invent skills: A2 is not written as C1. Sentinela is not a government careers office.

## What is usual
- Professional photo
- Nationality and **permit G, B, C or L**
- Languages with CEFR level
- 1–2 pages, chronological, dates DD.MM.YYYY
- Language of the ad; if German, Arbeitszeugnis if you have one

## Official links
- Permit G (SEM): [sem.admin.ch]({sem_g})
- Working in Switzerland (SECO): [arbeit.swiss]({arbeit})
- Citizen portal: [ch.ch]({ch_ch})

Open a job listing → **CV for this job**. You paste text (it is not stored). Premium gives the letter for **that** listing.
