# Schweizer CV für eine Stelle

Das **verschafft dir die Stelle nicht**. Wir erfinden keine Kompetenzen: aus A2 wird kein C1. Sentinela ist keine staatliche Berufsberatung.

## Was üblich ist
- Professionelles Foto
- Nationalität und **Bewilligung G, B, C oder L**
- Sprachen mit CEFR-Niveau
- 1–2 Seiten, chronologisch, Daten TT.MM.JJJJ
- Sprache des Inserats; auf Deutsch Arbeitszeugnis, wenn du eines hast
