# CV suizo para un puesto

Esto **no te consigue el trabajo**. No inventamos competencias: un A2 no se escribe como C1. Sentinela no es asesora laboral del Estado.

## Cómo se suele hacer
- Foto profesional
- Nacionalidad y **permiso G, B, C o L**
- Idiomas con nivel CEFR
- 1–2 páginas, cronológico, fechas DD.MM.AAAA
- Idioma del anuncio; en alemán, Arbeitszeugnis si lo tienes
