# CV suíço para um posto

Isto **não te arranja o posto**. Não inventamos competências: um A2 não se escreve C1. A Sentinela não é conselheira oficial.

## O que é habitual
- Foto profissional
- Nacionalidade e **autorização G, B, C ou L**
- Línguas com nível CEFR
- 1–2 páginas, cronológico, datas DD.MM.AAAA
- Idioma do anúncio; em alemão, Arbeitszeugnis se o tiveres
